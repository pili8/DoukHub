功能配置

允许其他设备（手机、平板等）通过 HTTP API 调用 DoukHub 进行解析或下载

启用 API 接口
其他设备调用时需在 Header 中传入: X-API-Key: <密钥>
POST /api/v1/works/resolve  — 解析链接，返回下载地址 JSON
POST /api/v1/works/download  — 解析 + 本地下载，返回结果 JSON
GET  /api/v1/status         — 检查服务状态
Header: X-API-Key: <密钥> · Content-Type: application/json
curl -X POST http://<本机IP>:2999/api/v1/works/resolve \ -H "X-API-Key: dk_xxxx" \ -H "Content-Type: application/json" \ -d '{"links": "https://www.douyin.com/video/xxx"}'

每行一个映射, 格式: 缩写=完整标签。未匹配的缩写会作为新标签保留。

示例: 个=个人 | 图=图集 | 街拍=街拍 | 太多=多
