# 长列表折叠（前 N 行 + 展开全部）Design

**日期:** 2026-09-02
**状态:** 待评审

## Goal

全站统一长列表折叠：默认只显示前 20 行，超过时追加「展开全部（共 X 条）/ 收起」按钮，避免增量采集等页面被长列表撑长、下方内容难以找到。

## 背景

增量采集页「账号明细与日志」展开后一次性渲染全部账号，账号多时页面极长，批次历史和实时日志被推到很下面；账号行内展开的「作品明细」同理。其他页面（账号总览、采集记录、导入预览）也有无上限的长表格。

## 设计

### 1. 统一折叠工具（base.html）

新增一个可复用 JS 函数，所有目标页面共用同一机制：

```
clipList(container, { limit = 20, onToggle })
```

- 作用对象：容器的直系子行（`<tr>` 或 `<li>`），不含工具条自身。
- 若行数 ≤ limit：不显示按钮，原样展示。
- 若行数 > limit：隐藏第 limit+1 行起的行；在容器末尾追加一行工具条：
  - 收起态文案：「展开全部（共 X 条）」
  - 展开态文案：「收起」
- 点击切换：展开显示全部行，收起恢复前 limit 行。
- 返回 `{ toggle() }`，展开状态由调用方持有，以便重渲染后恢复。
- 工具条复用现有 CSS 变量（`--text-muted` 等），小字居中；不新增复杂样式。
- 工具函数放在 `base.html` 的全局 script 区，任何页面可用。

### 2. 应用清单

| 页面 | 容器 / 渲染函数 | 说明 |
| --- | --- | --- |
| collect.html 增量采集 | `#run-account-table`（运行批次账号行） | 轮询重渲染，展开状态必须保持 |
| collect.html 增量采集 | 每账号作品明细 `run-works-list`（`<ul>`） | 每个账号的作品标题列表同样限 20 |
| collect.html 增量采集 | `#run-account-table`（运行批次账号行） | 轮询重渲染，展开状态必须保持 |
| collect.html 增量采集 | 每账号作品明细 `run-works-list`（`<ul>`） | 每个账号的作品标题列表同样限 20 |
| sync/import.html 导入预览 | `#preview-body` | JS 渲染后 clip |

### 3. 增量采集实时刷新不重置

`showRunningDetail()` 每次轮询都整表重渲染。用模块级变量记录各容器当前是否处于「展开全部」状态；重渲染后如果曾展开，则重新展开，避免每刷新一次缩回去。

### 4. 与现有开关的关系

- 保留「展开账号明细与日志」大开关：它控制整个面板显隐。
- 新折叠按钮只作用于面板内的长列表（账号明细表、作品明细），两者互不干扰。

### 5. 交互细节

- 总数 X 取容器内实际行数（排除工具条）。
- 展开/收起按钮不触发表格排序、筛选等其他逻辑。
- 工具条不计入总数 X，也不参与行筛选（按 class `list-clip-bar` 排除）。

## 非目标（不加折叠）

- accounts.html / history.html：遗留模板，无页面路由（仅 /api/accounts、/api/history 接口），不修改。
- collect.html 批次历史（#batch-table-body）：已有「加载更多」分页（每页 20 条）。
- collect.html 批次详情弹窗：已有「显示 X / Y 条 + 加载更多」分块；弹窗自身带滚动，本次不动。
- table.html 表浏览：已有分页（50/100/200）。
- collect/overview.html 最近批次：服务端已固定只取最近 5 条。
- sync/overview.html 账号健康度表：已有限高滚动（max-height:420px）。
- sync/overview.html 最近处理结果表：固定几步，量小。
- database.html 错误详情：已有 5 条截断 + 「还有 N 个错误」。
- collect_detail.html：单作品采集页，无长列表。
- 不改变任何后端接口、数据量、分页；纯前端展示层改动。

## 验收标准

1. 增量采集运行中，账号 > 20 时明细表默认显示 20 行 + 「展开全部（共 X 条）」；点击展开全部后，轮询刷新不缩回。
2. 每个账号展开的作品明细，标题 > 20 时同样折叠。
3. 导入预览超过 20 行时可展开/收起。
4. 展开状态下再次点击「收起」恢复 20 行；原「展开账号明细与日志」开关行为不变。
5. 行数 ≤ 20 时不出现任何按钮，页面与改动前一致。
