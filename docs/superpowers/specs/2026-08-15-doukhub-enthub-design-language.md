# DoukHub EntHub-Style Design Language

- 日期: 2026-08-15
- 状态: 待审阅
- 范围: 全站视觉语言、核心页面重构、数据库基础治理

## 1. 背景

DoukHub 当前界面已经具备完整功能，但视觉上仍像默认 Material 管理模板：按钮偏大、卡片层次过多、表格和状态组件缺少统一细节，页面看起来不够完整。EntHub 则有更明确的作者风格：暖白背景、细边框卡片、紧凑控件、软色状态徽章、统一弹窗和本地图标。

本设计不是复制 EntHub 的布局，而是复用其设计语言:

- EntHub: 顶部导航、赤陶主色、Flask + htmx、企业数据浏览工具。
- DoukHub: 左侧导航、蓝色主色、FastAPI + 轮询、内容采集运行台。

两个项目应能看出是同一作者的产品，但保留各自的产品身份。

## 2. 目标

1. 建立一套 DoukHub 自己的设计系统，气质与 EntHub 相近。
2. 保留左侧导航和当前蓝色主色。
3. 保留现有侧边栏选中态的蓝色高亮块和左侧白色竖向指示条。
4. 重构核心页面的信息层级和组件细节。
5. 全站页面共享同一套按钮、卡片、表单、表格、状态、弹窗、toast 和空状态。
6. 数据库先做基础治理，不进行大规模业务表迁移。

非目标:

- 不照搬 EntHub 的顶部导航。
- 不把 DoukHub 主色改成赤陶色。
- 不引入 htmx 或更换前端技术栈。
- 不在本轮重构本地主数据表、标签关系表或 FTS5。
- 不改变采集、同步、TTD 和飞书的业务逻辑。

## 3. 设计原则

### 3.1 同作者但不同产品

共享:

- 紧凑控件密度
- 细边框卡片
- 软色状态徽章
- 表格 hover 和分页气质
- 统一弹窗和 toast
- 本地图标资源
- 清晰的空状态

保留差异:

- DoukHub 使用左侧导航
- DoukHub 使用蓝色主色
- DoukHub 保持采集运行台和同步向导的工作流差异

### 3.2 从模板感到工具感

当前问题:

- Material 大按钮和过大的圆角让页面显得空。
- 多层卡片嵌套降低层级清晰度。
- 页面缺少统一的 page head 结构。
- 状态、标签、表格和日志样式分散。

调整方向:

- 降低控件高度和页面噪音。
- 用细边框和浅背景区分层次，减少阴影。
- 每个页面有明确标题、摘要和主操作。
- 数据表成为页面主体，而不是被多个装饰卡片包围。

## 4. 设计令牌

### 4.1 色彩

DoukHub 保留蓝色主色，但表面色改为 EntHub 式暖中性色:

| 令牌 | 值 | 用途 |
|---|---|---|
| `--dh-background` | `#FBFAF7` | 页面背景 |
| `--dh-surface` | `#FFFFFF` | 卡片和表格表面 |
| `--dh-surface-muted` | `#F5F2EC` | 输入、表头、次级面板 |
| `--dh-text` | `#1F1B17` | 主文字 |
| `--dh-text-secondary` | `#5C564E` | 常规辅助文字 |
| `--dh-text-muted` | `#A39E96` | 弱提示 |
| `--dh-border` | `#ECE7DF` | 默认边框 |
| `--dh-border-strong` | `#D9D3C8` | 强边框 |
| `--dh-accent` | `#0061A4` | 主色，沿用当前蓝色 |
| `--dh-accent-hover` | `#004F8A` | 主色 hover |
| `--dh-accent-soft` | `#E7F0F8` | 主色浅底 |
| `--dh-danger` | `#C2410C` | 危险 |
| `--dh-warning` | `#B45309` | 警告 |
| `--dh-success` | `#16A34A` | 成功 |

蓝色与暖中性表面搭配，使 DoukHub 与 EntHub 有相同的纸面质感，但仍保持自己的品牌色。

### 4.2 圆角与间距

| 令牌 | 值 |
|---|---|
| `--dh-radius-sm` | `6px` |
| `--dh-radius` | `8px` |
| `--dh-radius-lg` | `12px` |
| `--dh-space-1` | `4px` |
| `--dh-space-2` | `8px` |
| `--dh-space-3` | `12px` |
| `--dh-space-4` | `16px` |
| `--dh-space-5` | `20px` |
| `--dh-space-6` | `24px` |

卡片圆角从当前 Material 大圆角降到 8-12px，控件圆角降到 6px。

### 4.3 字体与字号

- 继续使用系统字体栈。
- 页面标题: 20px / 600。
- 页面副标题: 13px / `text-secondary`。
- 卡片标题: 14px / 600。
- 正文: 13px。
- 辅助文字: 12px。
- 表格正文: 13px。
- 日志和 ID: mono 12px。

### 4.4 阴影

默认卡片不使用阴影，只用边框。悬浮和弹窗使用轻阴影:

```css
--dh-shadow-sm: 0 1px 2px rgba(31, 27, 23, 0.04);
--dh-shadow-lg: 0 8px 24px rgba(31, 27, 23, 0.12);
```

## 5. 全局组件规范

### 5.1 左侧导航

保留当前左侧导航结构和 40px 紧凑项。

选中态是本项目的识别特征，必须保留:

```text
选中背景: 蓝色主色
选中文字和图标: 白色
左侧指示条: 白色，3px 宽，高度 60%，圆角 0 3px 3px 0
```

这个白色竖向指示条是用户明确喜欢的细节，不允许在后续实现中移除。

折叠态继续显示图标，展开态显示图标和文字。

### 5.2 按钮

按钮高度:

- 默认: 34px
- 小按钮: 28px
- 页面主操作: 36px

规则:

- 主按钮: 蓝色实底、白字。
- 次按钮: 白底、细边框、次级文字。
- 危险按钮: danger 实底。
- 图标按钮: 28px 方形或圆形，必须有 `title` 或 aria label。
- 禁用态降低透明度并去除 hover。

### 5.3 卡片

统一结构:

```text
卡片标题行: 图标 + 标题 + 摘要，右侧操作
卡片内容: 表单、表格、流程或日志
```

规则:

- 白底、1px 边框、8px 圆角。
- 标题行下边距 12px。
- 不再出现卡片内再嵌套同强度卡片。
- 次级信息用分隔线或浅色面板，不用额外大卡片。

### 5.4 表格

- 外层为白色卡片，内部表格不另加边框。
- 表头: 12px / 600 / 次级文字 / 浅暖底。
- 行高约 40px。
- 单元格左右 padding 12px。
- 行 hover: 浅暖背景。
- 数字列使用 tabular numbers。
- 长文本 ellipsis，悬浮 title 显示完整内容。
- 操作列固定右侧，使用小按钮或图标按钮。

### 5.5 表单

- 输入高度 32px。
- label 12px / 500。
- 输入框白底、细边框、6px 圆角。
- focus: 蓝色边框 + 2px 蓝色 soft 外圈。
- 筛选表单使用紧凑网格，不使用大块卡片包装。

### 5.6 状态徽章

统一软色 badge:

| 状态 | 样式 |
|---|---|
| 等待 | 灰色 soft |
| 运行 / 启用 | 蓝色 soft |
| 成功 / 完成 | 绿色 soft |
| 失败 / 禁用 | 红色 soft |
| 跳过 / 取消 | 橙色 soft |

状态必须包含文字，不只依赖颜色。

### 5.7 弹窗与 toast

沿用 DoukHub 自绘弹窗，禁止原生 `alert/confirm/prompt`。

弹窗:

- 宽度 420px，最大 90vw。
- 圆角 10px。
- 标题 15px / 600。
- 正文 13px。
- footer 右对齐。

toast:

- 右上角。
- 成功、失败、信息三类。
- 自动消失，不打断操作。

### 5.8 空状态

统一结构:

```text
图标
标题
一行说明
可选主操作
```

不使用大插画，不显示营销式说明文字。

### 5.9 图标

引入本地 Lucide 图标，替换核心页面和全局外壳中的 Phosphor 图标。

规则:

- 导航图标 18px。
- 按钮图标 14px。
- 表格操作图标 14px。
- 空状态图标 36px。
- 每次局部刷新或 SPA 替换后重新执行 `lucide.createIcons()`。

过渡期内非核心页面可保留 Phosphor，但最终应统一为 Lucide。

## 6. 页面设计

### 6.1 全局页面头

每个页面使用统一 page head:

```text
标题
摘要: 数量、时间或当前状态
右侧: 页面级主操作
```

页面头不做成卡片。

### 6.2 同步概览

定位: 数据准备向导。

结构:

1. 页面头: 标题、账号数量、一键同步按钮。
2. 四步流程条: 导入、解析、同步账号、更新。
3. 一键执行面板: 进度、当前步骤、停止。
4. 账号列表表格。

流程步骤使用紧凑卡片和 Lucide 图标，不再使用大图标和大段说明。

### 6.3 同步步骤页

统一结构:

1. 页面头。
2. 依赖提示条。
3. 执行面板: 执行、取消、进度、统计、日志。
4. 历史列表。

导入页额外保留解析预览表格。

### 6.4 采集运行台

定位: 日常增量采集控制台。

结构:

1. 页面头: 当前状态、最近采集时间、主操作。
2. 状态摘要条: 可采账号、首次全量、日常增量、配置跳过。
3. 筛选面板: 等级、标签、平台、模式。
4. 当前批次面板: 进度、当前账号、运行时长、成功/失败/跳过、日志、取消或重试。
5. 批次历史表格。
6. 次级 tab: 单作品采集。

批量采集始终是默认视图。

### 6.5 数据浏览

账号表、采集表、Cookie 表、批次表共享:

- 筛选工具栏
- 白色表格卡片
- 稳定列宽
- 分页条
- 软色状态
- 行操作按钮

表浏览页保留 AG Grid 能力，但视觉 token 与新设计系统一致。

### 6.6 设置与状态

设置页按分组卡片组织:

- 服务
- 存储
- 同步
- 安全

状态页显示服务卡片和健康指标，不再使用大块装饰卡片。

## 7. 数据库基础治理

本轮只做基础治理，不做大规模表结构迁移。

### 7.1 连接规范

每个 SQLite 连接统一设置:

```sql
PRAGMA journal_mode=WAL;
PRAGMA foreign_keys=ON;
PRAGMA busy_timeout=5000;
```

### 7.2 迁移版本

引入 `PRAGMA user_version` 作为 schema 版本。

规则:

- 每个迁移有固定版本号。
- 迁移只执行一次。
- 迁移失败要中止启动并输出明确错误。
- 不再只依赖 `CREATE TABLE IF NOT EXISTS` 判断升级完成。

### 7.3 模块边界

当前 `database.py` 已过大，后续拆分方向:

```text
app/core/db/
  connection.py   # 连接与 PRAGMA
  schema.py       # 表结构与迁移
  repositories/   # 按实体读写
  queries.py      # 复杂查询、筛选、排序、分页
```

本轮只建立边界和迁移基础，不强制搬完所有方法。

### 7.4 查询安全

复杂查询继续使用:

- 白名单排序字段
- 参数化筛选
- 明确 limit / offset
- 只读查询与写操作分离

### 7.5 暂缓事项

以下留给后续阶段:

- 本地主数据表与飞书缓存投影拆分
- `tags` / `account_tags` 关系表
- normalized 字段体系
- FTS5 全文索引
- settings 表化

## 8. 实施边界

第一阶段修改:

- `app/templates/base.html`
- `app/static/css/style.css`
- 同步概览与四个同步步骤页
- 采集页
- 状态页与设置页的核心样式
- 数据库连接与迁移基础

暂不修改:

- 采集 API
- TTD 批量进程逻辑
- 飞书同步逻辑
- 表格数据接口

## 9. 验收标准

1. DoukHub 保留左侧导航和蓝色主色。
2. 侧边栏选中态保留蓝色块和左侧白色竖向指示条。
3. 核心页面使用同一套新按钮、卡片、表单、表格、badge、弹窗和空状态。
4. 页面视觉与 EntHub 有明显同作者气质，但不是同一布局复制。
5. 桌面 1440px 和移动 390px 均无重叠、溢出或文本截断异常。
6. 浏览器控制台无 JavaScript 错误。
7. 所有既有测试通过。
8. SQLite 连接统一启用 WAL、foreign keys 和 busy timeout。
9. schema 迁移具备版本控制。
