# 统一工作流界面设计文档

- 日期: 2026-08-15
- 状态: 待审阅
- 范围: 同步概览、同步步骤页、采集页、共享工作流样式

## 1. 背景

同步功能目前呈现为一次性的数据准备向导，而采集是日常重复执行的工作。两者已有各自页面，但视觉结构、进度反馈、统计块、日志和状态样式分散在各模板内，页面体验不一致。

本设计建立一套共享的工作流界面语言，同时保留两类工作的心智差异:

- 同步: 数据准备向导，强调一次链式完成。
- 采集: 日常运行台，强调可重复增量执行和批次状态。

## 2. 目标

1. 同步与采集使用一致的卡片、按钮、进度、统计、日志、状态徽章、表格和空状态。
2. 同步保留 `导入 → 解析 → 同步账号 → 更新` 的步骤推进结构。
3. 采集首屏成为日常增量运行台，而不是同步流程的第五步。
4. 保留现有路由、API、任务逻辑和数据结构。
5. 消除同步页与采集页各自重复定义的样式，改为共享工作流样式。

非目标:

- 不改数据库、采集进程、TTD 配置生成和任务状态机。
- 不重做导航信息架构。
- 不新增业务功能。

## 3. 共享界面语言

### 3.1 工作流面板

统一卡片结构:

- 标题行: 图标 + 标题 + 辅助计数，右侧放主操作。
- 执行区: 主按钮、次要按钮、状态提示。
- 进度区: 进度条、当前动作、百分比。
- 统计区: 4 个等宽统计块。
- 日志区: 深色控制台样式，支持成功、失败、信息三类文本。

### 3.2 状态组件

统一状态徽章:

- 等待: 中性色
- 运行 / 启用: accent
- 成功 / 完成: success
- 失败 / 禁用: danger
- 跳过 / 取消: warning

状态语义不因页面变化。

### 3.3 表格与空状态

同步账号列表、采集批次历史、批次明细、定时任务使用同一表格密度和操作按钮尺寸。

空状态统一为居中图标、一行短说明，不使用大块插画。

## 4. 同步页面设计

同步页面定位为数据准备向导。

### 4.1 同步概览

顶部保留流程条:

```text
导入采集表 → 解析采集表 → 同步账号表 → 更新账号表
```

每个步骤节点显示:

- 序号
- 名称
- 一行说明
- 状态图标

节点点击进入对应步骤页。

一键执行面板保留在流程条下方，使用共享执行面板组件:

- 主操作: 一键同步
- 运行中: 停止
- 进度条与当前步骤
- 链式执行范围保持现状，不因流程条新增第 4 步而改变既有执行逻辑

账号列表保留在页面底部，使用共享表格样式。

### 4.2 同步步骤页

导入、解析、同步账号、更新账号使用同一布局:

1. 顶部提示条: 当前步骤依赖和服务条件。
2. 执行面板: 执行、取消、进度、统计、日志。
3. 历史记录: 可折叠历史项。

步骤页之间不再各自定义统计块和日志样式。

## 5. 采集运行台设计

采集页面定位为日常运行台，核心动作是“开始日常增量采集”。

### 5.1 顶部状态条

显示:

- 上次采集时间
- 上次成功账号数
- 当前运行状态
- 可采账号数摘要

无批次时状态为安静的中性样式; 有批次运行时使用 accent 强调。

### 5.2 日常增量面板

默认展开，包含:

- 评级筛选
- 标签筛选
- 平台筛选
- 采集模式，默认 `首次全量，后续增量`
- 预计账号数
- 主按钮: 开始日常增量采集

筛选变化时更新预计账号数。

### 5.3 当前批次面板

有批次时显示:

- 当前账号序号 / 总账号数
- 已运行时长
- 成功、失败、跳过数量
- 当前进度条
- 批次日志
- 取消按钮

无批次时显示最近一次批次摘要，并提供失败重试入口。

### 5.4 批次历史

表格列:

- 批次
- 平台
- 状态
- 账号数
- 成功
- 失败
- 跳过
- 开始时间
- 操作

操作包括详情、取消、失败重试。

### 5.5 单作品采集

单作品采集从主视觉降级为次级 tab:

- 粘贴链接
- 解析作品
- 选择保存目录
- 命名模板
- 下载作品

解析前下载按钮禁用。解析结果使用共享表格样式。

定时任务保留在采集页底部，使用共享表格和空状态。

## 6. 响应式与可访问性

- 桌面优先，保留现有应用信息密度。
- 小屏下流程条横向滚动，统计块两列，表格容器横向滚动。
- 按钮和输入控件沿用现有表单基础样式，焦点状态不变。
- 状态不仅依赖颜色，均附带文本。
- 页面文字不得溢出或遮挡。

## 7. 技术方案

- 在 `app/static/css/style.css` 新增共享工作流样式:
  - `.workflow-panel`
  - `.workflow-flow`
  - `.workflow-step`
  - `.workflow-metrics`
  - `.workflow-metric`
  - `.workflow-log`
  - `.workflow-status`
- 修改:
  - `app/templates/sync/overview.html`
  - `app/templates/sync/import.html`
  - `app/templates/sync/resolve.html`
  - `app/templates/sync/account.html`
  - `app/templates/sync/refresh.html`
  - `app/templates/collect.html`
- 保留页面脚本行为，仅调整 DOM 结构、类名和渲染位置。
- 新增只读查询接口 `POST /api/collection/batches/preview`。入参复用批次创建请求，返回预计账号数和上次采集摘要; 该接口不得启动批次或修改账号。

## 8. 验收标准

1. 同步概览、四个同步步骤页、采集页使用同一套工作流视觉语言。
2. 同步仍清晰表达一次性流程推进。
3. 采集首屏突出日常增量采集和当前批次状态。
4. 单作品采集可用但不再是主视图。
5. 桌面和移动端无文字溢出、元素重叠或布局跳动。
6. 浏览器控制台无 JavaScript 错误。
7. 既有测试全部通过。
8. 页面路由和业务 API 不变更。
