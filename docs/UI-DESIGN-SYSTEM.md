## 1. 核心原则

| 原则 | 说明 |
|------|------|
| **全 token 化，禁止硬编码颜色** | 所有颜色一律用 `var(--dh-*)`，不得写死色值（硬编码会导致深浅主题不跟随、多页不统一，历史教训：日志框 `#1a1c1e` 硬编码） |
| **深浅主题自动跟随** | 项目有完整暗色模式（`data-theme` 切换 + localStorage 记忆 + 跟随系统），用 token 即自动适配，零额外代码 |
| **风格统一优先** | 新组件先对齐项目已有范式（按钮 6px 圆角、卡片白底细边框、胶囊容器），不引入跳色 |
| **自用工具，精简文字** | 说明文字只留必要提示，删冗长解释 |
| **层次用填充强度表达** | 主次用 Filled / Tonal / Ghost 或浅深两档蓝，不用不同色相跳色 |

## 2. 主题机制

- 控制方式：`<html data-theme="light|dark">`（`style.css` 中 `:root` 与 `:root[data-theme="dark"]` 分别定义全部 token）
- 切换逻辑：`base.html` 内联脚本——`localStorage` 记忆用户选择，无记忆时跟随系统 `prefers-color-scheme`
- **规则：写样式永远引用 `var(--dh-*)`，让主题自动切换生效**

## 5. 语义色（状态 / 进度场景）

| 语义 | Token | 浅色 | 深色 | 用途 |
|------|-------|------|------|------|
| 进行中 / 信息 | `--dh-accent` | 蓝 | 亮蓝 | 日志 info、进度条、计数卡"总数" |
| 成功 | `--dh-success` | 绿 | 亮绿 | 日志 ok、分段条完成段、计数卡"成功" |
| 失败 | `--dh-danger` | 红 | 亮红 | 日志 err、分段条失败段、计数卡"失败" |
| 警告 | `--dh-warning` | 橙 | 亮黄 | 日志 warn、警告提示 |

**统一约定：进度 / 状态场景下，蓝=进行中、绿=成功、红=失败、橙=警告，全项目一致。**

| 组件 | 规范 |

## 7. 布局与间距

- 基准间距 16px；卡片内边距 20px；卡内区块间距 16px
- 单作品采集页固定四卡片结构：**作品链接 → 进度 → 资产结果 → 下载历史**
- 输入框操作按钮（粘贴 / 清空）悬浮于右下角，不占独立行
- 资产列表行高紧凑（缩略图 40px），超出限高滚动

## 8. 交互惯例

- **输入即反馈**：链接输入后即时预检，统计条一行汇总（数量 · 匹配数 · 平台计数），无效链接可点击定位
- **模式并列**：同一位置三按钮表示三种模式（解析 / 一键下载 / API），按钮动作 + 设置项联动
- **低频内容折叠**：音乐 / 封面等低频资产收进折叠组，默认收起只占一行
- **进度流式展示**：分段彩色进度条（完成=绿 / 进行中=蓝 / 失败=红 / 未到=灰）+ 当前消息 + 计数卡 + 日志行；解析=2 段、下载=3 段
- **下载方式**：本地 / 浏览器选择放在下载动作时弹出（不放在设置里）

## 10. 设置页结构（2026-08-21 定稿）

> 「整体设置页面」采用**分组 Tab + 折叠卡**，不做长滚动页。本节为结构决策记录。

### 10.1 分组 Tab 导航

- 顶部**分组 Tab**（DoukHub配置 / 下载与文件 / 内核服务 / 功能配置），点击切换面板（`.settings-group.active` 显隐），**不再滚动长页**。
- 组内仍可折叠卡（`.settings-card.open`）。
- 保留 `scrollToGroup` 兼容旧入口；支持 URL hash 直达分组（`#group-download`），供采集页「管理模板」等外部跳转。
- 深色主题 / 交互惯例沿用全 token 规范。

### 10.2 下载与文件分组结构

| 卡片 | 内容 |
|------|------|
| **保存方案** | 双卡横排：**增量采集**（按账号归档，根目录+平台/账号自动层级） / **单作品采集**（直存，默认目录留空则用增量根目录）；各卡含「编辑命名」直达统一编辑器 |
| **文件命名规则** | 统一命名编辑器：增量模板 / 单作品模板 小胶囊切换；字段**拉平** |
| **下载内容选项** | 增量附属下载（音乐/封面/大小上限/导出格式）；单作品附带下载在采集页「一键下载」设置 |

### 10.3 命名统一（字段拉平）

两套引擎字段**在 UI 层合并为同一套**，保存时按方案映射回引擎字段：

| UI 字段 | 增量引擎键 | 单作品引擎键 |
|---------|-----------|-------------|
| 发布时间 | `create_time` | `create_time` |
| 作品类型 | `type` | `type` |
| 作者 | `nickname` | `author` |
| 标题 | `desc` | `title` |
| 作品ID | `id` | `id` |
| 账号UID | `uid` | —（仅增量，角标） |
| 账号标识 | `mark` | —（仅增量，角标） |
| 平台 | —（仅单作品，角标） | `platform` |

- 编辑器同一套 chips，非当前方案可用字段自动隐藏，专属字段带「仅增量 / 仅单作品」角标。
- 单作品模板支持多模板 + 默认模板 + 「复制为增量」；字段编辑自动同步回当前模板并防抖持久化。
- **兼容性**：只改了前端 UI 与映射，后端 API（`/api/collection/defaults` 存 `name_format`、`/api/collection/single-work/preferences` 存 `{author}/{title}`）未变，存量配置零迁移。

### 10.4 共享命名工作台（2026-08-21 晚定稿 v6 → 落地）

> 用户批准 v6 布局原型，落地后的真实结构：**卡片内不再有命名编辑器**，统一收进**底部滑出式共享命名工作台**（单一 DOM 实例）。

#### 10.4.1 卡片区（两大组：单作品采集 / 增量采集）

| 组 | 内容 |
|----|------|
| 单作品采集 | 「保存目录」分区（方案目录 + 浏览，留空用增量根目录）+「命名」分区（**摘要行** + 「编辑模板」按钮，紫色强调） |
| 增量采集 | 「下载目录」分区（根目录 + 浏览 + 平台/账号目录树）+「命名」分区（摘要行 + 编辑模板，绿色强调）+「附属下载」分区（2 行格：第 1 行 音乐/动态封面/静态封面 开关；第 2 行 **文件大小上限在前**、**数据导出格式在后**） |

- 摘要行实时显示字段示例 + `.mp4`，字段顺序改动即时同步；「每作品独立子文件夹」开关已从批量卡移入工作台。

#### 10.4.2 底部共享命名工作台（`.workbench`，单一 DOM 实例）

- 触发：任一卡片「编辑模板」→ `openWorkbench('single'|'batch')`；遮罩点击 / 关闭按钮收起。
- 结构自上而下：
  1. **作用域胶囊**（单作品 / 增量）：`wbScope(s)` 切换，读写各自独立的 `tplState[scope].parts`；
  2. **模板管理条**（`#wb-tpl-sel`）：单作品=方案下拉（含默认标记）+ 新建 / 重命名 / ★设默认 / 删除 / 「设为增量默认」（`dupToBatch`，复制后自动切到增量作用域展示结果）；增量=固定「增量默认模板」占位（引擎级，无多方案）；
  3. **字段池**（`#wb-pool`）：chips 点击加入/移除命名，专属字段带「仅增量 / 仅单作品」角标；
  4. **排序带**（`#wb-belt`）：已选字段拖动换位、✕ 移除；
  5. **存储**（仅增量作用域显示）：「每作品独立子文件夹」开关（唯一保留的引擎级选项，`folder_mode`）；
  6. **预览**（`#wb-pv`）：文件名实时示例（分隔符 `-` 已固化）。
- JS 契约：`renderTplEditor(scope)` 幂等（摘要常驻 + 面板只渲染当前作用域）；`templateDragStart(event, scope, index)` 拖动签名修正了旧版参数错位；保存映射与 §10.3 一致，后端 API 未变。

## 11. 全局视觉标准 v2 —— 三层表面 + 蓝色强调（2026-09-05 草案，待确认）

> 本节将 §1-6 的令牌规范升级为**全站页面的强制标准**：所有页面（含表浏览、数据概览、备份、同步各页）新增/改动 UI 时逐条对照。
> 依据：v2.2.6（表浏览筛选面板）、v2.2.7（全局界面统一）两轮落地实践沉淀，已核对与 style.css / 各模板实现一致。

### 11.1 三层表面体系（空间层级，全站唯一的空间语言）

| 层级 | Token | 浅色值 | 角色 | 视觉感受 |
|------|-------|--------|------|---------|
| L0 页面背景 | `--dh-background` | `#FBFAF7` 暖白 | 最底层画布 | 平铺 |
| L1 卡片表面 | `--dh-surface` | `#FFFFFF` | 卡片 / 面板 / 弹窗 | 浮起（靠 1px 边框 + 阴影区分） |
| L2 降级面 | `--dh-surface-muted` | `#F5F2EC` 米色 | 日志、输入区、胶囊底、次级信息 | 凹下去、退后 |

**米色的正名**：米色是**降级面**，不是"着重面"。它的本职是让白卡浮起来、让次要内容沉下去。真正的"着重"是蓝色（实心按钮 + accent-soft 选中态）。

红线：
1. 一层卡片内**只套一层米色**（米色套米色会糊成一团）；
2. 米色块对比极弱，必须靠边框或内容自身站住，不能单独承担分区；
3. 弹窗、面板一律用 L1 白底，不得用米色打底。

### 11.2 蓝色强调的唯一性

| 强度 | 样式 | 用途 |
|------|------|------|
| 最强 | 实心蓝 `--dh-accent` 白字 | **主操作**，一屏内只允许一个 |
| 次强 | `--dh-accent-soft` 浅蓝底 + 蓝深字（tonal / halo） | 选中态、筛选高亮、次级主打项 |
| 中 | 白底 + 1px 边框描边（`.btn-secondary`） | 次要操作 |
| 弱 | ghost 灰字虚线框 | 仅展示型入口 |

- **选中态 halo 模式**：`accent-soft` 底 + `--dh-accent` 深字（+ 可选 1px 蓝边），用于筛选按钮选中、Tab 激活、列菜单选中项。
- 一屏内蓝色实心按钮 > 1 个即视为违规；"一屏"指视口内同批操作区。

### 11.3 文字与对比度红线

- 三档文字：`--dh-text`（正文）/ `--dh-text-secondary`（次级）/ `--dh-text-muted`（弱化）。
- `--dh-text-muted`（`#9C9387`，对白底约 **2.7:1**）**只允许用于辅助小字**（时间戳、计数、占位符），禁止承载正文——正文 AA 要求 4.5:1。
- 实心蓝按钮白字约 6.3:1，达标；深色模式下语义色自动提亮，无需逐页适配。

### 11.4 状态与语义色（全站唯一约定）

**语义约定：蓝 = 进行中/信息，绿 = 成功，红 = 失败，橙 = 警告。** 进度条分段、计数卡、日志行、状态徽章全部遵守，不得换色相。

| 场景 | 规范 |
|------|------|
| 表浏览状态胶囊 | halo 浅底 + 深字（沿用）：待解析=灰、已就绪=蓝、已生成=绿、已删除=橙、解析失败=红 |
| 任务/历史状态 | 一律映射 `--dh-warning / --dh-accent / --dh-success / --dh-danger` 语义令牌，禁止 JS 里写死 hex |
| 日志行 | `.log-ok / .log-err / .log-info / .log-warn` 四类 |

- **页局部补充色模式**（如设置页紫色）：在该页 `<style>` 顶部定义 `--dh-purple / --dh-purple-soft` 两枚页局部令牌（明暗各一档），页面内只引用令牌；全局 `style.css` 不为其扩表。

### 11.5 复用组件规范（v2.2.6 / v2.2.7 已落地，新页面直接套用）

| 组件 | 类名 | 规范要点 |
|------|------|---------|
| 日志面板 | `.log-panel` / `.workflow-log` | L2 米色底 + 等宽字体 + 语义色行；**禁止深色黑底**（"终端感"靠等宽字体与语义色行表达，不靠黑底） |
| 空状态 | `.empty-state` | 三段式：`es-title`（14px/600）+ `es-desc`（12px muted，可省）+ `es-action`（主/次按钮，可省）；小容器加 compact 变体；图标居中 |
| 区块卡头 | `.card h3` | 图标 chip 化：accent-soft 圆角小底 + accent 图标 + 标题，右侧留动作区；全局统一，不再各页自定义 |
| 指标卡 | `.db-stats-enhanced .stats-card` | 左侧语义色竖条（`--sc-color` 注入）+ 大数字（tabular-nums）+ 次级说明；悬停轻微浮起 |
| 全局进度浮条 | `.global-progress-chip` | 胶囊造型 + 呼吸图标 + 细进度条；暂停态加 `.is-paused`（图标转警告黄、停止呼吸） |
| 折叠卡 | `.settings-card` | chevron 旋转 90° + 高度过渡动画；展开态才显示 `.open` |
| 筛选弹窗 | `.tbl-filter-popup` | L1 白底 + 分组小标题（排序 / 筛选值）+ 头部分隔线 + 检索内嵌清空按钮 + 底部主按钮加宽加粗 |

### 11.6 硬编码禁令与新页面自检清单
